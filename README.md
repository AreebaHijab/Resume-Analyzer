# Resume Analyzer 

An web application that analyzes resumes, provides feedback, and gives tips to improve your resume for better job opportunities.

🔗 **Live Demo:** https://AreebaHijab.github.io/Resume-Analyzer/

### ✨ Features
- User Authentication (Login / Register)
- Resume Upload and Analysis
- Dashboard with personalized feedback
- AI-based Tips & Suggestions
- Clean and Responsive UI

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend / Auth:** Firebase Authentication
- **Data:** JSON
- **Hosting:** GitHub Pages

### 🚀 How to Use
1. Clone the repository
2. Open `index.html` in browser
3. Register / Login
4. Upload your resume and get instant analysis
